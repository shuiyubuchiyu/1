# 中国象棋 - 局域网联机游戏

一个基于 Node.js 和 Socket.IO 的局域网联机中国象棋游戏。

## 功能特点

- 🎮 支持局域网内多人联机对战
- 🏠 房间系统，可自定义房间号
- ♟️ 完整的中国象棋棋盘和棋子
- 🔄 实时同步棋局状态
- 📱 响应式设计，支持多种设备

## 安装步骤

1. 确保已安装 Node.js (建议 v14+)

2. 进入项目目录：
```bash
cd chinese-chess
```

3. 安装依赖：
```bash
npm install
```

## 启动服务器

```bash
npm start
```

服务器将在 `http://localhost:3000` 启动。

## 局域网访问

1. 查看本机 IP 地址：
   - Windows: `ipconfig`
   - Mac/Linux: `ifconfig` 或 `ip addr`

2. 让其他设备访问：
   ```
   http://你的IP地址:3000
   ```

## 使用方法

1. **创建/加入房间**：
   - 第一个玩家输入房间号（如：room1）并点击"加入游戏"
   - 第二个玩家输入相同的房间号加入

2. **开始游戏**：
   - 当两个玩家都加入后，游戏自动开始
   - 红方先行

3. **移动棋子**：
   - 点击自己的棋子选中
   - 点击目标位置移动或吃子

4. **胜负判定**：
   - 吃掉对方的将/帅即获胜

## 技术栈

- **后端**: Node.js + Express + Socket.IO
- **前端**: HTML5 + CSS3 + JavaScript
- **通信**: WebSocket 实时双向通信

## 注意事项

⚠️ 当前版本为简化版，主要实现基本功能：
- 实现了基本的棋子移动
- 尚未实现完整的走棋规则验证（如马走日、象走田等）
- 适合休闲娱乐使用
